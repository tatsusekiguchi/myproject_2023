Message

美容を通じて広がる“幸せの輪”

“スタッフ” “お客様” “お店” この三つは
“幸せの輪”の循環に欠けてはならないものとwaccaは考えます。
ひとつひとつの接客術丁寧に積み重ねお客様へ美しさを届ける。
そしてお客様の日常にお店が入ることで、

waccaはそんな思いを大切に“幸せの輪”を広げます。

Technical check

技術試験

waccaでは各項目毎に「入客テスト」と「最終テスト」の2段階に分けて技術テストを行い入客回数も増やしながら自信を持ってスタイリストデビューができる仕組みです。カリキュラムをベースに個々に合わせたペースで取り組み、自身の得意不得に向き合いながら、一緒に成長していくことができます。

01｜入客テスト

入客テストでは、実際のお客様に対し時間を要しても快適に過ごしていただける接客や施術ができるかどうかを見ます。

02｜実践入客

合格後は、実際にスタイリストと一緒に現場へ入ります。必ずスタイリストがフォローに入るので、お客様にも安心感を持ってもらえます。

03｜最終テスト

最終テストは、ウィッグでのテストです。色々なパターンを学んで一つの施術を一人で任せられるレベルになったかどうかを確認します。

04｜項目合格

項目合格後は、その項目を1人で入客することができるようになります。入客を増やすことは技術向上だけではなく、自身の売上にもつながります。

代表取締役安井 隆一

楽しく広がる“成長の輪”

この2段階テストの仕組みを導入しているのは、営業後のトレーニング時間を短縮し、少しでも早い時期から多くのお客様の髪質やスタイルに触れることで、それに合わせたテクニックを習得することができるからです。
また、1年目の最初のトレーニングがカラーなのもシャンプーは一人で行う施術ですが、カラーはスタイリストが横でフォローしながらできるからです。少しでも多く入客してお客様と接する時間を作り、自分が塗ったカラーでお客様に喜んでいただけることの喜びを感じてもらいたいという思いからこの順番となっています！

model cut

モデル料はウィッグ購入や材料費、
講習費としてスタッフに還元

モデルに関しては営業中にモデルを入れ、頂いたモデル料はウィッグ購入や材料費、講習費としてスタッフに還元します。
考え方はアシスタントトレーニングと同じで、ウィッグの反復練習も大事ですが、ウィッグ代もかかり時間を使うよりもモデルで実践的に練習しモデルさんから頂いたモデル代でウィッグに還元することでお給料の中からウィッグ代を捻出することをなるべく抑える工夫をしています。

働く環境を見る

How we work

01

アシスタントから
生産性に合わせた歩合性。

waccaでは仕事の生産性に合わせて歩合をつけています。デビューしたスタイリストだけではなく、細かな仕事が多くなるアシスタントの生産性にも目を向けてしっかりと評価し、還元していきたいと考えています。デビュー後も空いている時間があれば、他の人のヘルプに入ったりなど、忙しさが評価され、還元される。働くことの“嬉しさ”につながる。そんなスタッフの気持ちを大切にした仕組みを採用しています。

How we work

02

黒川駅、徒歩1分。
郊外だから落ち着けるサロン。

黒川駅から徒歩1分の場所にwaccaはあります。はじめての一人暮らしもしやすい街で、郊外には少ないデザインやトレンドに強いサロンを展開しています。にぎやかな街サロンとは違い、柔らかな雰囲気で時間がゆっくりと流れていくような、地域の方々が通いやすいサロンを目指しています。

How we work

03

バランス型のカリキュラムで、
悩みに寄り添える美容師に。

大手の老舗サロンでの実績を上げたオーナースタイリストがマンツーマンでスタッフ指導に向き合い、営業時間内にカリキュラムを進めてながらデビューを目指します。カリキュラムはバランスを重視しており、しっかりと基礎を底上げすることでデビュー後の売上アップや技術をサポートします。接客面でもひとりひとりが持つ人間性や個性を見ながら、お客様のあらゆる悩みや要望に柔軟に応えていける美容師としてレベルアップしていくことができます。

How we work

04

外部の技術講習
サポートも充実。

waccaでは営業時間内の練習のみらず、メーカーやディーラーの外部講習にも参加ができます。美容師にとってメーカーやディーラーは美容師のあらゆることをサポートをしてくれるチームです。メーカーやディーラーが主催の講義などに参加しサロン外の人とのコミュニケーションをとりながら、同じ世代の美容師たちとの交流の場にもなり、自分自身やサロン自体へも刺激を受けることができます。

Owner message

オーナーの思い

スタッフが将来のビジョンを
描き・叶えやすいサロンに

代表取締役

安井 隆一YASUI RYUICHI

waccaでは、スタッフ・お客様・お店の3つがそれぞれ幸せであれば、その幸せが循環し、さらに大きな幸せの輪となり広がると考えています。特に“スタッフ”は、“お客様”と“お店”を直接繋ぐ大切な存在です。美容師の幸せや満足感が、サロンの繁栄とお客様の満足につながります。スタッフの「やりたい」に寄り添って応援していく、クリエイティブにしてもサロンワークにしても自分から成長をしていけるサロンを目指しています。全員が幸せでないと輪っかにはなりません。コミュニケーションや技術に自信がないスタッフもwaccaではしっかりフォローする仕組みづくりをしています。北区・黒川という地域を中心に輪の様に広がる大きく太い濃い幸せな輪を、仲間と広げてwaccaを中心に喜びや楽しみをみんなで共有しましょう。
