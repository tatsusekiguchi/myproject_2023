美を通じて愛を届ける

「あの人にもっと綺麗になってもらいたい」「あの人のお悩みを解決したい」
そういった愛ある想いが技術を磨いたり勉強に励んだりする大きなエネルギーになると考えています。
「美容が好きだから。」はもちろん、お客さまへの愛を美を通じて届けたい、そんな想いのあるスタッフに来てほしいと願っています。

そしてお客さまだけでなく、一緒に働くスタッフにも愛をもって接することができる人を求めています。
アークでは一番のVIPはスタッフだと考えています。
チームで仕事をしているからこそ、技術や知識を共有したり、思い遣りのある声がけをしたり、気持ちよく仕事ができるようサポートし合うことができます。
みんなが明るい気持ちで働き、お互い成長し合えるような環境があるからこそ、お客さまにもより良いサービスが提供できると信じています。

人を愛し、人から愛される仲間をお待ちしています。

アークが大切にしていること

CORE VALUE

01

技術力より人間力

アークでは何よりも人間力を大切にしています。
素直で前向きな人間力のある人は、経験を積むごとに技術力も自然と上がっていきます。
アークではグループサロンで「人間力を養う勉強会」を実施し、入社後も人間力を高められる環境を整えています。

02

キャリアを途切れさせない

子どもが生まれ育児が始まると、美容師のキャリアが中断されることが多くあります。
何年も現場から離れると技術や流行が進んでいるため、復帰することが難しくなってしまいます。
アークは自社で保育園を運営し無料で預かり、柔軟なシフトで働ける環境を整えています。
キャリアを中断せず、自分に合った働き方を選ぶことで、美容師として長く働き続けることができます。

キャリア復帰について

03

チームワークを重視

私たちは個人でやっているわけではありません。
共に働くスタッフが同じ方向を向き、お互いを支え合い成長していけるようなチームを目指しています。
困った人がいれば余裕のあるメンバーがサポートし、新しい技術や知識は積極的に共有する。
そうすることでスタッフ全員が気持ちよく働き、お客さまへのサービスが向上すると考えています。
