トラストについて

TRUST

トラストとは

TRUSTの意味は「信用」です。
常にお客様の立場に立って考え丁寧に施工を行い信用される仕事をしたい
そう思い、この会社名にしました。
「信用と品質を形に」
職人の確かな技術であなたの住まいを守ります。

Features

トラストの特徴

Features

01

イメージ通りになる
カラーシミュレーション

小さな色見本帳やカタログから、大きな外壁の色を選ぶのは難しいものです。
トラストでは家の外壁や屋根の塗り替えを検討する際、塗り替え完了後をイメージして頂けるよう、カラーシミュレーションや色見本板を使いながら、イメージを共有して決めていきます。試し塗りも行っているので、お客様の理想の色に仕上げることができます。

Features

02

仲介業者が入らない自社施工

私たちは直接塗装工事を請け負っているため、余計な仲介費用がかかりません。
そのためリフォーム会社や工務店よりお得な価格で、丁寧な施工を行うことができます。お得だかからこそ、その分工事の仕上がりを重視するための塗料費や補修・塗装の作業費にまわすことができます。選択肢が広がるため、お客様のご予算に合わせながら仕上がりを希望することができます。

Features

03

経験と知識からのご提案

日の当たる時間や道路に面しているかどうかなどさまざまな場所にある家は、傷み具合や症状が違い同じ状態の家はひとつもありません。トラストでは、実際に職人がお家を拝見させていただき、お客様に合った家の塗り替えのご提案をさせていただきます。経験と知識を活かし、大切なお家を守るために何が必要かを真剣に考え、わかりやすく丁寧にご説明いたします。

Features

04

確かな技術の施工力

経験豊かな職人の知識をもとに家の状態・素材から判断して、最適な施工を行っていきます。使う道具や塗料、下地の塗り方によって、家の持ちは格段に良くなります。
上手い職人の家の塗り替えとは、見た目が美しく塗料の強みを最大限に発揮し長持ちするものです。
トラストでは常に学び続ける姿勢を忘れず、職人ひとり一人が責任を持って施工を行っていきます。

reason

選ばれる理由

01

お客様に合った塗装時期の見極め

外壁塗装は築10年前後が目安と言われていますが、家の立地や周りの環境によって劣化の進行状況は変わってきます。現状施工が必要なければ、しないといった提案もする場合もございます。トラストは建物診断をして、お客様の家に本当に必要なご提案をいたします。

02

きちんと測量いたします

塗装において測量は大切な作業です。この測量によってお客様の家の見積もりが決まります。トラストは、図面だけを見て見積もりを出すことはしません。また最新のドローンルーファーを使用した測量では、実際にお客様と家の状態を見ながらお客様に合った見積もりを出すことが可能です。

03

強引な営業はしません！

何度も営業の電話をしたり、訪問営業は一切していません。お客様が「必要」と感じ、ご納得いただいて初めてサポートをしていきます。安心して見積もりの依頼をしていただます。

04

助成金申請サポート

お住まいの地域によっては、平均して10 ～ 25 万円の助成金が出る場合もあります。トラストでは、無料で申請のサポートをさせていただきます。
申請手順なや受給条件など、丁寧にご案内いたします。

05

安心アフターサポート

塗ったら終わりではありません。トラストでは、お客様の家を守るため、施工後の保証体制の充実にも力を入れています。
